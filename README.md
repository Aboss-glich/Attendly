# 🚀 Attendly — School & Coaching Management System

**Attendly** is a modern full-stack school/coaching management system designed to simplify student management, teacher management, attendance tracking, reporting, notifications, and role-based access.

🌐 **[Live Demo](https://attendly-ktan.onrender.com)**

---

## ✨ Features

* 🔐 Role-based authentication
* 👑 Owner/Admin/Teacher/Student access
* 🧑‍🎓 Student management
* 👨‍🏫 Teacher management
* 👨‍👩‍👧 Parent management
* 🟢 Attendance management
* 📱 QR-based attendance check-in
* 📊 Dashboard statistics & analytics
* 📈 Attendance reports
* 🔔 Notification system
* 📝 Leave management
* 🔍 Student and teacher management
* ⚙️ Settings & account management
* 🛡️ Security and audit features
* 📱 Responsive design
* ✨ Modern premium UI

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Attendly
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the server

```bash
npm start
```

### 4. Open in browser

```text
http://localhost:5000
```

> The production deployment uses the port provided by the hosting platform.

## 🔐 Security

Sensitive runtime files and secrets are intentionally excluded from the public repository.

Examples:

```text
.env
auth-users.json
storage.json
node_modules/
*.log
```

These files should remain private in production.
